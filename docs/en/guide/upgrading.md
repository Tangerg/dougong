# Upgrading

Identify your installed version and target version, then follow each intervening migration guide in version order.
For example, upgrading from 0.8.3 to 0.12.0 requires the 0.9.0, 0.10.0, 0.11.0 and 0.12.0 migrations in sequence.

This index lists the available migration documents and release notes. Check your package manager to confirm that your target version has been published.
