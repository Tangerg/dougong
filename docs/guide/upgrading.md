# 升级指南

先确认项目安装的版本与准备升级到的目标版本，再按版本顺序阅读两者之间的迁移指南。
例如，从 0.8.3 升级到 0.11.0，需要依次完成 0.9.0、0.10.0 和 0.11.0 的迁移。

下表索引已有的迁移文档与发布说明；目标版本是否已经发布，请以包管理器中的版本为准。

| 目标版本 | 迁移步骤 | 发布说明 |
| --- | --- | --- |
| 0.9.0 | [迁移到 0.9.0](./migrating-to-0.9.md) | [0.9.0 Release Notes](../reference/release-0.9.0.md) |
| 0.10.0 | [迁移到 0.10.0](./migrating-to-0.10.md) | [0.10.0 Release Notes](../reference/release-0.10.0.md) |
| 0.11.0 | [迁移到 0.11.0](./migrating-to-0.11.md) | [0.11.0 Release Notes](../reference/release-0.11.0.md) |
